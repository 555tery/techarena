# Правила работы с этим проектом

- Начинай с [wiki/Home.md](wiki/Home.md) и читай только страницы по текущему вопросу.
- Не загружай целиком `results/`, входные потоки, журналы прогонов или `scientist-v3/upstream/`: это данные и архив, а не справочный контекст.
- Для результата конкретного эксперимента проверяй его короткий отчёт и манифест. Не считай старые числа из корневых документов текущими.
- Держи wiki-страницы тематическими, ориентир — до 120 строк и 8 KB; при росте разбивай страницу и обновляй индекс.
- Не удаляй и не перемещай архивные данные и экспериментальные артефакты без отдельного запроса.
- Пользователь остановил оптимизационные эксперименты. Не возобновляй их и не взаимодействуй с платформой без нового прямого запроса. Если пользователь попросит открыть сайт, разрешён только просмотр таблицы лидеров; тесты и отправки на сайте запрещены.
- Новая прямая авторизация 18 октября 2026: автономно максимизировать конкурсный счёт, по возможности сохранить обобщаемость, остановиться при остатке любого доступного лимита Codex <65%. Действует для `research-campaigns/20261018T141843+0700-autonomous` до 21:00 Asia/Novosibirsk; разрешены локальный поиск и отправка проверенных лучших решений на NSUts. Старый Shinka и старый validation не возобновлять; после квотной или ручной остановки не запускать автоматически. Подробности: [политика платформы](wiki/operations/Platform-policy.md), `manifest.json` и `supervisor.json` этой кампании.
