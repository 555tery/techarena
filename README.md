Полный исследовательский проект по задаче «Трубопровод»: C++ и Cangjie, online-ядра, replay, генераторы, тесты, проверки и история экспериментов.

- [Навигация по проекту](wiki/Home.md).
- [Последние 20 вариантов и их сохранённые проверки](VERSIONS.md).
- [Полный снимок исследовательских данных](https://github.com/555tery/techarena/releases/tag/snapshot-2026-10-23): все допущенные к публикации файлы, включая большие результаты и трассы.

Исходники, документация, основные манифесты и журналы доступны непосредственно в дереве Git. Полный снимок содержит около 582 тысяч файлов (19,7 GB до сжатия, с дубликатами). Установленные SDK, окружения, кэши, служебные Git-истории, воспроизводимые бинарники и файлы учётных данных исключены. Локальные оригиналы сохранены. Полный список исключений: [reproducibility/excluded-local-paths.jsonl](reproducibility/excluded-local-paths.jsonl).

## Восстановление полного проекта

Скачайте из [Release](https://github.com/555tery/techarena/releases/tag/snapshot-2026-10-23) все `project.tar.zst.part-*` и `SHA256SUMS` в одну папку:

```sh
shasum -a 256 -c SHA256SUMS
mkdir restored
cat project.tar.zst.part-* | zstd -d | tar -xpf - -C restored
```

Одинаковые файлы упакованы через hard links; нужна файловая система с их поддержкой. [Манифест снимка](reproducibility/snapshot-files.jsonl.gz) содержит исходные пути, размеры и SHA-256. Переносимый список 3029 входов и дополнительные внешние входы лежат в `reproducibility/`; полные исходные пути восстанавливаются из архива. Сохранённые временные скрипты последнего раунда — `reproducibility/recovered-tools/`.

Для компактной коллекции 3081 входа достаточно Git-клона:

```sh
python3 tools/unpack_tests.py unpacked-tests
```

Исходные команды сборки последних вариантов: `versions/*/manifest.json`. Cangjie требует отдельный SDK. Проект содержит сторонние исходники с их лицензиями; история сторонних Git-репозиториев не включена.
