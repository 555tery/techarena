# Независимые временные механизмы

Этот каталог содержит только генератор и заранее объявленный дизайн. Solver,
старые генераторы, Open15, прежние validation, campaign metrics и traces при его
реализации не читались. Независимость относится к реализации и новым seeds;
распределение скрытых тестов неизвестно, и соответствие ему не утверждается.

`design.json` задаёт 12 семейств, четыре независимых base streams каждого
семейства и пять literal prefixes каждого base: **48 bases, 240 tests**.
Для десяти длинных семейств длины 12000/32000/80000/200000, для двух micro —
80/160/240/400. Длина связана с номером rep заранее, не выбирается по результату.

Пять cutoffs: **20/40/60/80/100%**. Первая смена режима происходит на25%,
drain/reversal — на65–75%. Содержимое prefix — строго первые cutpoint команд
общего base; меняется только заголовок n. Хвосты ради конечной загрузки не меняются.
Часть окончаний заранее содержит drain, часть growth. Случаи F=0 сохраняются:
поле `zero_final_volume` описывает нулевой числитель независимо от размещения.

Micro ограничивает объём живых объектов60, что даёт нижнюю объёмную оценку
1–3 секции при ненулевой загрузке. Это не ограничение траншеи solver: размещение
может потребовать больше секций. Нулевые состояния явно учитываются.

В `prefix_branch` один независимый base реализует одну из четырёх заранее
назначенных ветвей после общей для его контрфактических ветвей prefix-процедуры.
Сохраняется fingerprint фактического prefix. Разные bases имеют разные seeds
и длины: **paired branches с одинаковым фактическим prefix здесь нет**.

До генерации root одобряет дизайн и замораживает solvers, генератор и дизайн.
Нужен JSON freeze с `schema_version:1`, `design_approved:true`, SHA256 полями
`generator_sha256`, `design_sha256` и словарём `solver_sha256` с ключами
`trial22`, `bf`, `ss`. Дополнительные protocol/evaluator/checker/binary hashes
сохраняются в freeze без интерпретации. Генератор не читает файлы solvers.

```sh
python3 selftest.py
python3 generate.py --output /ABS/NEW_OUTPUT_DIRECTORY --freeze /ABS/freeze.json
```

Генератор отказывает при отсутствии/несовпадении freeze и при существующем
output. Только после этих проверок `secrets` создаёт master seed и48 независимых
per-base seeds; master — сохранённая provenance entropy, не ключ derivation.
Все seeds сохраняются до построения потоков. `STATUS=INCOMPLETE` при незавершении;
существующий output нельзя автоматически продолжить или перезаписать. Даже при
ошибке нельзя выбирать новые seeds по замеченным метрикам.

Manifest сохраняет freeze, seeds, параметры, фазовые границы, base/test hashes,
cutpoint roles и статистику независимого повторного разбора команд. Объём,
число объектов, пики и histogram arrival sizes не используют адреса или solver.
Основные active/group операции O(1), FIFO/LIFO amortized O(1), deadline heaps
O(log n); сортируются только micro sets<=60 и motif batches<=48.

Root независимо проверяет входы и оценивает не более двух native workers при
официальных5s/256MiB. Агрегация: сначала пять prefixes внутри base, затем четыре
bases внутри family, затем12 families. Cutoff results сообщаются отдельно;
240 prefixes нельзя считать240 независимыми наблюдениями. Никаких platform,
API, установок, score filtering или resampling этот генератор не выполняет.

После чтения финальных данных генератор и дизайн не изменять. Tiny self-test
использует фиксированные учебные seeds и не создаёт финальные streams.
