Что удалось уменьшить

План разбит на участки, которые ни одна труба не пересекает. Их перестановка сохраняет корректность всех известных lifetime-трасс. Для каждого допустимого отношения T/BF из ограничений на все префиксы строятся предельные позиции участков. Порядок по этим ограничениям позволяет найти лучший максимум в данном классе перестановок. Fallback: предложить, проверить, затем выполнить

Online-алгоритм работает на копии состояния. Его ответ принимается только если требует не больше новых секций траншеи, чем BF из той же физической раскладки. Если предложение проигрывает по немедленному рытью, оно отбрасывается до печати ответа. Эпизод ограничен существующими бюджетами модели: 32 предложения и 4096 живых труб. Условие преимущества относительно параллельного causal BF сохранено.

При передаче управления промежутки заново строятся по реальным активным трубам. Внутренний список online-политики может исключать ещё свободные участки, зарезервированные под будущие трубы. Копирование такого списка теряло бы доступную ёмкость. Независимый тест снимка: старый перенос не находит свободный [30,70), новый корректно размещает там трубу длины 40 без рытья.

Граница гарантии. Проверка предложения ограничивает немедленный расход из текущего состояния. Она не доказывает, что итоговая траншея будет не длиннее BF: разные размещения меняют будущую фрагментацию. Код по-прежнему использует полные открытые потоки для предварительной подготовки планов.
