# Индекс результатов Pipes

- [`final/`](final/README.md) — замороженный проверенный артефакт, SHA, манифест и результаты Open15/holdout-v2.
- [`improvement/`](improvement/README.md) — отдельные исследовательские ветки; см. также [короткий индекс экспериментов](../../wiki/research/Index.md).
- [`REPORT_FOR_MANAGER.md`](REPORT_FOR_MANAGER.md) — сохранённая точка входа к отчёту, разбитому на страницы в [wiki](../../wiki/reports/manager/README.md).
- `final-open/`, `final-holdout-v2/`, `final-policy4/`, `policy-comparison/` — более ранние локальные прогоны и сравнения; для текущего frozen final используй `final/`.

Подробное различие canonical source и frozen final: [wiki/solution/Artifacts](../../wiki/solution/Artifacts.md).
