# Age tie-break: bounded screen and Open-15 gate

## Проверяемая policy

На изолированной копии frozen baseline добавлен один причинный tie-break: среди допустимых свободных интервалов одинаковой длины выбирается интервал с самым ранним `birth_op` (наибольший текущий возраст). При одинаковом возрасте сохраняется прежнее предпочтение стороны/адреса. Cost по разным длинам, cohort rules и прочие решения не менялись. Возраст ведётся только для текущего интервала и сбрасывается при его создании после split/merge. Код не читает номер теста или будущие команды.

## Почему этот один тест был выбран

В retrospective subset из exact survivor audit target был старше lower-address same-size representative в 29,383/31,719 событий (92.6%); медианная разница — +2,425 операций. Это только сигнал для проверки: gaps отобраны по EOF-выживанию и будущему fitting demand, поэтому эта корреляция сама по себе не доказывает причинный выигрыш.

## Ранее использованный `final-holdout-v2`

Этот набор уже использовался раньше и не засчитывается как независимая проверка. Вспомогательный парный прогон показал score sum 5.13526432 → 5.13566775 (Δ +0.00040342), но mixed per-case effects: case02 улучшился на 20 м, cases01/07 ухудшились на 20/80 м. Этот слабый плюс не компенсировал регрессию на Open-15.
