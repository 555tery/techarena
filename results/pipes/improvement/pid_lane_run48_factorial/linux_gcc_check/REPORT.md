# Linux/GCC gate для PID/46

**Дата:** 2026-10-17. Проверен только локальный точный исходник PID/46; сайт и платформа не использовались.

## Результат

Исходник SHA-256 `1a643a2b8a560de5c7dfd7efe0b288dc93785e96400d2ae6fd4ec7eea5f55f59` побайтно совпадает с `sources/pid_run46.cpp` из факторной qualification. Он собрался на Linux aarch64, Debian 13.7, GCC 14.2.0 с C++20 и `-Wall -Wextra -Wconversion -Wshadow -pedantic -Werror`. Это доступный в проекте Linux/GCC target-профиль. Сборка и локальный официальный harness завершились без ошибок.
