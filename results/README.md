# Индекс результатов

- [Pipes](pipes/README.md) — основной frozen-final артефакт и большой архив локальных экспериментов.
- `review-*.json` и `review-harness-controls/` — результаты аудита и проверки harness.
- `strategy-*` — ранние матрицы и отладочные прогоны allocator-политик; подробности и текущие границы версий — в [wiki](../wiki/Home.md).

Не сканируй `results/` целиком: там много больших трасс, логов и per-case выводов. Начинай с тематического README и открывай конкретный manifest или отчёт.
