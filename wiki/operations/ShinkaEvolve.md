# ShinkaEvolve локально через Codex

Подготовлен 17 октября 2026 г. в [`shinka-pipes/`](../../shinka-pipes/README.md).
Использует отдельную `.venv`, закреплённые версии ShinkaEvolve и Headless и
существующую ChatGPT-авторизацию Codex CLI. Docker не требуется.

## Текущий статус

- Установка и проверки конфигурации выполнены без запросов к модели; позднее
  выполнен только baseline-only прогон на поисковой синтетике.
- Принудительно задан billing `subscription`; переход на платный API запрещён.
- API embeddings, meta-рекомендации и W&B отключены.
- Явно закреплены модель текущего чата `gpt-6.1-sol` и reasoning `xhigh`;
  настройка CLI `gpt-6-luna` больше не используется.
- Активная задача `task-synthetic/` использует только search: 32 синтетических
  потока из 16 семейств. Отдельный validation: 24 потока из 20 семейств,
  включая четыре механизма, отсутствующих в search.
- Fitness — среднее `B/T` с равным весом семейств (`B` — объёмная нижняя граница).
  Search baseline: **0.914983819101**, 32/32, максимум CPU **1.189802 s**,
  RSS **6.96875 MiB**; исходный local leader сохранён без изменений.
- Validation выполняется вручную для зафиксированного кандидата и не возвращается
  в Shinka. Open15 сохранён и исключён из поиска/validation; он уже влиял на baseline
  и не является независимым holdout. Старая настройка `task/` не удалена.
- Связка compile → interactor → harness → fitness проверена на baseline/search.
  Fitness независимо пересчитан; [отчёт и манифест](../../shinka-pipes/baseline-runs/20261017T231804+0700/REPORT.md).
  В baseline-only прогоне модель, validation и Open15 не запускались.
- По прямому запросу пользователя запущен поиск на **20 поколений включая gen 0**:
  [run-manifest](../../shinka-pipes/runs/20261017T232542+0700-833000/run-manifest.json).
  Используется только search, в том числе на этапе preflight. Validation и Open15
  не проверяются и не оцениваются. Текущее состояние — в `shinka-pipes/active-run.json`.
- 18 октября исправлен ложный отказ из-за конечного перевода строки в diff;
  пять кандидатов успешно переоценены, тот же прогон возобновлён с общим target20.
  [Восстановление и учёт бюджета](Shinka-recovery-20261018.md).

содержит URL/PID, `progress_ui.py` — обёртка штатного WebUI. Панель не запускает оценки.


нельзя. Платформа не используется.
