# Agentic Scientist v3

Это отдельная экспериментальная интеграция. Операционный справочник находится в [`scientist-v3/README.md`](../../scientist-v3/README.md); task snapshot — в `scientist-v3/tasks/pipes/`.

На момент настройки он использовал старый стартовый baseline `29.4471645435 / 32.1`, поэтому его README не описывает текущий frozen final. В `upstream/` находится сторонний checkout, а рядом есть `.venv`, кэши и временные каталоги; не открывай их как обычную документацию.

Запуск с `--run` инициирует внешнего coding agent внутри контейнера и расходует настроенный ключ OpenCode. Не запускай его без нового прямого запроса пользователя.
