# Карта каталогов

| Путь | Содержимое | Как читать |
|---|---|---|
| `src/` | Канонический C++-исходник и родственные версии | Не путать с frozen final в `results/pipes/final/`. |
| `data/pipes/` | Условие, 15 открытых входов, synthetic и holdout-входы | Входы большие и обычно не нужны для чтения документации. |
| `vendor/pipes_official/` | Официальный interactor и заголовок | Источник локальной проверки. |
| `tools/`, `review/` | Harness, сравнение, аудит корректности | Читай нужный скрипт, не весь каталог. |
| `experiments/` | Симуляторы и генераторы потоков | Исследовательская инфраструктура. |
| `docs/` | Протокол и более ранние описания алгоритма/проверки/стратегий | См. раздел ниже: несколько страниц относятся к старым версиям. |
| `results/pipes/final/` | Frozen final, manifest, бинарники и официальные локальные прогоны | Авторитетный источник для frozen final. |
| `results/pipes/improvement/` | Каталог отдельного эксперимента: отчёт, исходник, манифест и прогоны | Не сканировать рекурсивно: много крупных логов и машинных трасс. Начинать с [индекса](../research/Index.md). |
| `results/` | Исторические сравнения, артефакты аудита, промежуточные результаты | Локальные `score.txt` и логи не являются итоговой сводкой. |
| `scientist-v3/` | Отдельный AI-Scientist эксперимент, upstream и его runtime | Внутри есть `.venv`, npm cache, рабочие контейнеры и логи; не включать это в общий контекст. |
| `shinka-pipes/` | Локальный ShinkaEvolve через Codex по подписке | Начинать с README; `.venv`, `runtime/node_modules`, сторонние checkout и `runs/` не загружать как справочный контекст. |
| `wiki/` | Короткая навигация по проекту | Начинай с [Home](../Home.md). |

## Документы с историческими результатами

- [`docs/ALGORITHM.md`](../../docs/ALGORITHM.md) описывает ранний T46 (`29.4471645435`), а не frozen final.
- [`docs/REVIEW.md`](../../docs/REVIEW.md) проверяет старый исходник SHA `a5241956…e8ae3` и score `28.375837599`; это не аудит текущего frozen final.
- [`docs/STRATEGIES.md`](../../docs/STRATEGIES.md) — раннее сравнение Best Fit и других простых политик, до последующих версий.
- [`scientist-v3/README.md`](../../scientist-v3/README.md) фиксирует состояние AI-Scientist на момент настройки и старый baseline; для текущей версии смотри [статус](Current-state.md).
- Корневой [`score.txt`](../../score.txt) содержит историческое `0.5`; текущие результаты берутся из конкретных manifest/summary и не вычисляются по этому файлу.

## Примечание о структуре

При осмотре 17 октября 2026 г. в корне не было каталога `.git`. Поэтому текущие изменения документации не имеют локального git diff/undo; машинные результаты и бинарники здесь намеренно не перемещаются.
