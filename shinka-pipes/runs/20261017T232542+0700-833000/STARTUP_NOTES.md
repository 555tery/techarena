# Запуск Shinka: 20 поколений, только search

Лимит — 20 поколений, включая baseline gen 0. Модель — gpt-6.1-sol, reasoning xhigh,
billing subscription. В evaluator и preflight используется только поисковая синтетика.
Validation и Open15 не проверяются и не оцениваются.

Первый старт `20261017T232349+0700-482000` остановлен из-за ошибки импорта:
Shinka копирует evaluate.py в results directory, поэтому относительный путь к
synthetic_eval.py оказался неверен. Результатов корректных новых кандидатов там нет;
один вызов модели мог начаться до остановки. Артефакты этого старта сохранены.

Исправление: явный PIPES_SHINKA_ROOT в окружении и переносимая обёртка evaluator.
Проверена загрузка скопированного entrypoint в изолированном Python. Добавлен gate:
реальный вызов модели запрещён, пока gen 0 не прошёл все 32 search-теста.
Все 7 проверок runtime/safety прошли без validation/Open15.

Текущий запуск подтвердил gen 0: correct=true, 32/32, fitness 0.9149838191013845.
На момент записи запущен Codex для gen 1; новых проверенных улучшений ещё нет.
Дальнейшее состояние отражают evolution_run.log, gen_*/results и SQLite database.
Это статус старта, не отчёт о завершении всех 20 поколений.
